when AnkiDroid requests that preference. In AnkiDroid 2.26.0alpha6, "1" is the
supported never-report mode and avoids the ACRA configuration/initialization path.
The saved reportErrorMode choice is not replaced. AnkiDroid's own supported
never-report path can write ACRA's separate disable flag. Other apps and other
preferences are unchanged. Timber/Husk logs remain enabled; ACRA reporting is
disabled while using this test build.

Host checks passed for missing/saved report modes, saved-value preservation,
other apps, message copying, preview isolation, and collection relocation.
DEX comparison against V3 found only the intended string-getter change; native
executables and all other retained IPA entries match V3 except the build label.
ZIP integrity passed. Installation/startup on iPad is not verified.

Test startup first: the ACRA service error and report-preparation dialog should
no longer appear if this workaround is effective. Crash Reports Enabled should
be false if AnkiDroid prints that status. Let media sync finish, then test one
plain card. If it closes again, send that run's complete Husk report.

For lag, Husk's per-app Display > Resolution can be set to Low, followed by a
full restart. Lower resolution may reduce drawing work, but it is not a native
